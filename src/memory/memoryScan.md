🚀 Финальный пошаговый план разработки тестового задания
🧩 Этап 1. Структура проекта

Цель: подготовить основу для всех модулей приложения.

Создай проект на React Native с TypeScript (это прямо указано в требованиях).

Настрой React Navigation с экранами:

HomePage

BarcodeScannerPage

WiFiPage

EventsPage (лог событий)

MapPage

Добавь глобальное хранилище (например, Zustand или Context) для хранения:

отсканированных штрих-кодов;

найденных Wi-Fi сетей;

событий пользователя (events).

📸 Этап 2. Сканер штрих-кодов

Цель: продемонстрировать работу с камерой и управлением списком данных.

Подключи react-native-vision-camera или expo-barcode-scanner.

Реализуй:

сканирование штрих-кодов с камеры;

добавление каждого кода в список (без дубликатов — уникальный id);

событие “Сканирование штрих-кода”.

Сделай экран со списком кодов:

возможность удалять свайпом;

возможность перетаскивать элементы (drag & drop);

возможность отмечать элемент маркером (второй пункт свайпа);

при отметке → событие “Отметка маркером кода”;

при удалении → событие “Удаление кода”.

📶 Этап 3. Работа с Wi-Fi

Цель: продемонстрировать работу с системными API Android.

Используй react-native-wifi-reborn (Expo не поддерживает Wi-Fi API).

Реализуй:

кнопку “Сканировать сети”;

вывод списка Wi-Fi сетей (SSID + RSSI уровень сигнала);

кнопку “Подключиться” — имитация, без проверки подключения (Alert('Подключено')).

Добавляй события:

“Запуск поиска Wi-Fi точек”;

“Подключение к Wi-Fi”.

🧠 Этап 4. Лог событий

Цель: собрать все действия пользователя в одном месте.

Создай экран EventsPage.

Логируй события при:

открытии приложения;

сканировании штрих-кода;

отметке кода маркером;

удалении кода;

запуске поиска Wi-Fi;

отправке пуш-уведомления.

На странице событий отобрази:

название события;

дату в формате ДД.ММ.ГГГГ ЧЧ:ММ:СС (по Киеву);

дополнительные поля (например, SSID или barcode).

Добавь:

иконку для перехода на страницу событий с любого экрана;

кнопку “Копировать событие” (копирование текста в буфер обмена).

🗺️ Этап 5. Интеграция с Google Maps

Цель: визуализировать найденные Wi-Fi точки на карте.

Подключи react-native-maps.

Запроси разрешения на геолокацию.

Отобрази:

текущее местоположение пользователя;

маркеры найденных Wi-Fi сетей — можно сгенерировать координаты в радиусе 50–100 м от пользователя.

При открытии карты добавляй событие “Отображение карты”.
